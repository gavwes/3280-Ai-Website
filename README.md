# 3280-Ai-Website
Website showing the environmental impact of everyday AI use

**The Cost of a Prompt**, ANTH 3280 Final Project by Gavin Simpkins, Fernando Tello and Owen Rogers.

## Viewing the site
No install needed. Double-click `index.html` to open it in your browser.

## Files
| File | What it is |
| --- | --- |
| `index.html` | Overview: the problem, key stats, prompt calculator |
| `energy.html` | Electricity use and carbon emissions |
| `water.html` | Water use and affected communities |
| `action.html` | Call to action and pledge checklist |
| `css/styles.css` | All styling (colors are set at the top) |
| `js/main.js` | Mobile menu, scroll animations, calculator, pledge |
| `images/` | Illustrations (SVG). Put any photos here too |
